
# Student Performance Analysis Using Python

## Project Overview

This project analyzes student academic performance
using Python and Data Science libraries.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Features

- Dataset loading
- Data preprocessing
- Missing value handling
- Total and average calculation
- Performance categorization
- Statistical analysis
- K-Means clustering
- Data visualization
- CSV output generation

## Output

The project generates an analysed CSV file
and four graphical visualizations.
